# Security Policy

Do not submit confidential legal documents, credentials, personal data or exploit details in public issues. Use synthetic reproductions.

Provider API keys must remain outside version control. The runtime does not guarantee that information sent to a remote provider remains local. Tool adapters must validate inputs, minimize disclosure, use allowlisted destinations and return structured errors without secrets or source content.

This project does not guarantee legal confidentiality, privilege preservation, anonymization or regulatory compliance. Attorney and organizational review remain necessary before processing sensitive material.

Until a private reporting channel is published, open only nonsensitive security issues. If a safe public reproduction is impossible, do not disclose the vulnerability publicly.
