# Contestación federal para Puerto Rico

## Workflow

1. Calcular el término de respuesta y documentar servicio y mociones que lo afecten.
2. Responder cada alegación con admisión, negación o falta de conocimiento fundada.
3. Identificar defensas afirmativas sin fórmulas vacías ni reservas genéricas.
4. Evaluar contrademandas, terceros, jurado y preservación de objeciones.
5. Mantener consistencia con expedientes, documentos y posiciones previas.
6. Entregar contestación, matriz de admisiones y temas que requieren investigación.

## Salida

Entrega un borrador estructurado, hechos faltantes, autoridades verificadas, incertidumbres, riesgos y próximos pasos.

## Fuentes y control de calidad

Verifica reglas federales y locales, órdenes del caso, estatutos y precedentes vinculantes en fuentes oficiales vigentes. Marca citas pendientes como `UNVERIFIED`, minimiza datos personales y exige revisión independiente por abogado.
