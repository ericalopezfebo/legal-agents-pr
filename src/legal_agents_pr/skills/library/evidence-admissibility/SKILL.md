# Admisibilidad de evidencia

1. Identificar pieza, propósito, proponente, testigo, etapa y hecho que pretende probar.
2. Analizar pertinencia y balance antes de reglas especiales.
3. Evaluar conocimiento personal, autenticación, mejor evidencia y cadena de custodia.
4. Para declaraciones, precisar declarante, aseveración, propósito y excepción potencial.
5. Revisar privilegios, carácter, impugnación, peritaje y limitaciones constitucionales según proceda.
6. Formular objeción específica, respuesta, fundamento y oferta de prueba para preservar el asunto.
7. Distinguir admisibilidad, peso y suficiencia.
8. Verificar regla vigente y jurisprudencia; no inventar contenido, fundamento ni autenticación.
