# Protocolo ESI

## Algoritmo

1. Identificar foro, órdenes, reclamaciones, custodios, sistemas, volumen y recursos.
2. Definir alcance, fechas, fuentes, datos inaccesibles y procedimiento para controversias.
3. Acordar métodos de recopilación, deduplicación, búsqueda, validación y muestreo.
4. Precisar formatos, metadatos, numeración, familias, texto, imágenes y medios especiales.
5. Regular privilegio, clawback, redacción, confidencialidad, datos personales y sellado.
6. Establecer autenticidad, hash, cadena de custodia, logs y control de calidad.
7. Coordinar producciones suplementarias, errores, costos, terceros y modificaciones.
8. Verificar compatibilidad técnica antes de comprometer herramientas o formatos.

## Salida

Entregar protocolo, diccionario de producción, matriz de decisiones técnicas, temas abiertos y mecanismo de escalamiento.
