# Revisión contractual

1. Confirmar partes, capacidad, objeto, ley aplicable, fecha, anexos y versión operativa.
2. Extraer obligaciones, condiciones, fechas, pagos, renovaciones, terminación, remedios y dependencias.
3. Evaluar cada cláusula por riesgo, ambigüedad, conflicto interno, ausencia y efecto operacional.
4. Estructurar: cláusula, riesgo, explicación, autoridad, recomendación, lenguaje sugerido, confianza y verificación.
5. Distinguir texto contractual, interpretación jurídica y preferencia comercial.
6. Revisar integración, prelación, cesión, indemnización, seguros, confidencialidad, datos y controversias según proceda.
7. No inventar términos ausentes ni presentar una práctica comercial como requisito legal.
8. Verificar autoridades y Derecho transitorio antes de recomendar una cláusula como obligatoria.
