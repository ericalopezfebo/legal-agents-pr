# Moción de desestimación federal

## Workflow

1. Identificar la base procesal exacta y si puede renunciarse o conservarse.
2. Separar ataques jurisdiccionales, suficiencia de alegaciones y otros fundamentos.
3. Definir el universo de materiales que el tribunal puede considerar.
4. Aplicar el estándar pertinente a cada reclamación y remedio.
5. Anticipar enmienda, conversión, discovery jurisdiccional y disposiciones parciales.
6. Redactar introducción, estándar, argumento, remedio y orden propuesta.

## Salida

Entrega un borrador estructurado, hechos faltantes, autoridades verificadas, incertidumbres, riesgos y próximos pasos.

## Fuentes y control de calidad

Verifica reglas federales y locales, órdenes del caso, estatutos y precedentes vinculantes en fuentes oficiales vigentes. Marca citas pendientes como `UNVERIFIED`, minimiza datos personales y exige revisión independiente por abogado.
