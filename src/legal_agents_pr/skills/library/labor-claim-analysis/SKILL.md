# Reclamación laboral

1. Clasificar relación: privada, pública, unión, contratista o régimen especial.
2. Construir cronología de contratación, políticas, eventos protegidos, medidas adversas y terminación.
3. Mapear elementos, cargas, defensas y remedios de cada causa sin mezclar estatutos.
4. Evaluar cobertura, patrono, empleado, agotamiento, foro y términos.
5. Separar prueba directa, inferencias, comparadores, razón legítima y pretexto.
6. Calcular salarios y daños por escenarios, identificando datos faltantes.
7. Verificar ley vigente para la fecha de cada evento y efectos de reformas o anulaciones.
8. No presentar una política interna, convenio o práctica como hecho sin el documento aplicable.
