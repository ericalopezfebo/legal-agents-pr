# Revisión administrativa

1. Identificar agencia, ley orgánica, procedimiento utilizado, parte afectada y remedio solicitado.
2. Confirmar orden final, notificación, reconsideración, agotamiento y término de revisión.
3. Separar jurisdicción, debido proceso, autoridad delegada, hechos, Derecho y discreción.
4. Delimitar expediente administrativo y estándar de revisión para cada planteamiento.
5. Evaluar excepciones a agotamiento y jurisdicción primaria sin presumirlas.
6. Verificar LPAU, ley especial, reglamento, decisiones y cambios temporales aplicables.
7. Identificar remedio: confirmar, revocar, modificar, devolver, ordenar actuación o medida provisional.
8. No completar hechos, trámites, notificaciones ni contenido del expediente ausente.
