# Transacción de marca

1. Confirmar partes, autoridad, titularidad, cadena de título, registros, solicitudes, oposiciones y controversias pendientes.
2. Definir con precisión signos, bienes o servicios, territorio, canales, usuarios autorizados, exclusividad y derechos reservados.
3. Separar licencia, cesión, consentimiento, coexistencia y acuerdo de solución; identificar el efecto jurídico buscado en cada jurisdicción.
4. Revisar uso permitido, presentación, atribución, control de calidad, inspección, cambios, expansión, sublicencia y asignación.
5. Mapear contraprestación, informes, auditoría y registros únicamente según las instrucciones comerciales verificadas.
6. Establecer notificación, manejo de confusión real, enforcement frente a terceros, cooperación y control de controversias.
7. Analizar duración, incumplimiento, cura, terminación, inventario, retiro de uso y supervivencia sin inventar plazos.
8. Verificar si el acuerdo requiere registro, presentación o consideración por una oficina o tribunal; no garantizar aceptación.
9. Señalar cláusula, riesgo, razón, autoridad verificada, recomendación, propuesta y asuntos pendientes de aprobación profesional.
