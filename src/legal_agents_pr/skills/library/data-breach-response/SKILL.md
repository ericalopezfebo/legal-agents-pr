# Respuesta a violaciones de datos

## Algoritmo

1. Abrir una cronología privilegiada con detección, contención, investigación, decisiones y notificaciones.
2. Identificar entidad, sistemas, custodios, proveedores, residentes afectados, lugares y sectores regulados.
3. Preservar evidencia y coordinar investigación forense sin alterar registros ni atribuir causa prematuramente.
4. Clasificar datos y cifrado conforme a las definiciones vigentes de cada régimen potencialmente aplicable.
5. Evaluar separadamente Ley 111-2005 de Puerto Rico, contratos, reglas sectoriales federales y leyes de otras residencias.
6. Construir una matriz de destinatario, evento activador, término, contenido, método, excepción, regulador y prueba de cumplimiento.
7. Preparar comunicaciones claras sin admitir hechos no confirmados ni obstaculizar investigación oficial.
8. Coordinar aseguradora, orden público, proveedores, relaciones públicas y preservación bajo funciones definidas.
9. Documentar decisiones, incertidumbres, medidas correctivas y aprobaciones.

## Salida

Entregar cronología, mapa regulatorio, matriz de notificación, borradores pendientes y estado `REVISIÓN DE ABOGADO REQUERIDA`. Verificar el texto oficial vigente antes de calcular términos.
