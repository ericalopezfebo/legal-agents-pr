# Informe pretrial federal

## Workflow

1. Leer scheduling order, órdenes particulares, reglas locales y formularios vigentes.
2. Organizar estipulaciones, controversias, teorías, daños, testigos y exhibits.
3. Vincular cada testigo y exhibit con propósito, fundamento y objeción prevista.
4. Identificar mociones in limine, issues de jury instructions y asuntos de logística.
5. Eliminar datos personales innecesarios y marcar hechos no confirmados.
6. Entregar informe estructurado, listas de verificación y pendientes para conferencia.

## Salida

Entrega un borrador estructurado, hechos faltantes, autoridades verificadas, incertidumbres, riesgos y próximos pasos.

## Fuentes y control de calidad

Verifica reglas federales y locales, órdenes del caso, estatutos y precedentes vinculantes en fuentes oficiales vigentes. Marca citas pendientes como `UNVERIFIED`, minimiza datos personales y exige revisión independiente por abogado.
