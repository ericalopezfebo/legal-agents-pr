# Revisión de confidencialidad

1. Identificar destinatario, propósito, autorización, foro y canal de divulgación.
2. Clasificar confidencialidad profesional, privilegio, producto del trabajo, orden protectora, sello y privacidad por separado.
3. Aplicar minimización: compartir solo lo necesario para el propósito autorizado.
4. Revisar texto visible, comentarios, cambios controlados, propiedades, nombres de archivo, anexos y metadatos.
5. Señalar información de menores, salud, finanzas, identificadores y secretos comerciales.
6. Evaluar renuncia, divulgación inadvertida, clawback y deber de notificar cuando corresponda.
7. No asumir que anonimizar nombres elimina privilegio o confidencialidad.
8. Detener la divulgación si falta autoridad o existe riesgo material no resuelto.
