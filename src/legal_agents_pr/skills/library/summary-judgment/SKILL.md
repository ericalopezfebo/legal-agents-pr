# Sentencia sumaria

1. Identificar elementos, cargas probatorias y asuntos que pueden resolverse sin juicio.
2. Preparar hechos materiales numerados, separados y sustentados con referencias precisas.
3. Distinguir evidencia admisible, inferencias razonables y argumentos jurídicos.
4. Para oposición, admitir o controvertir cada hecho con referencia específica; no usar negaciones globales.
5. Excluir hechos irrelevantes, conclusiones y citas sin punto de referencia.
6. Analizar sentencia total, parcial y remedios restantes.
7. Verificar términos, formato, páginas, anexos y autenticación antes de presentar.
