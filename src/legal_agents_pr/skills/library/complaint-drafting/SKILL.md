# Redacción de demanda

1. Confirmar tribunal, competencia, jurisdicción, partes, capacidad, emplazamiento y remedio solicitado.
2. Crear una matriz de elementos por causa de acción y asociar cada elemento con hechos disponibles.
3. Excluir conclusiones sin apoyo; identificar hechos faltantes antes de redactar.
4. Organizar epígrafe, alegaciones jurisdiccionales, partes, hechos numerados, causas y súplica.
5. Alegar hechos de forma clara, cronológica y compatible entre causas alternativas.
6. Separar daños, remedios, honorarios e intereses según su fundamento verificable.
7. Revisar prescripción, condiciones precedentes, agotamiento y documentos indispensables.
8. No inventar fechas, cuantías, anexos, citas ni gestiones de notificación.
9. Entregar como `DRAFT` con lista de verificaciones previas a presentación.
